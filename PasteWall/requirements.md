# 局域网共享剪贴板 · 需求文档

- 版本:v0.1(草稿)
- 日期:2026-08-16
- 状态:待评审

---

## 1. 背景与问题

用户家中局域网内有:1 台 Windows 电脑、2 台 Mac、1 台常开的 Linux 服务器(下称"服务器",Ubuntu 22.04)。

日常需要在 **Windows 与 Mac 之间传递文字和图片**(字符串、截图、图片等)。当前做法是通过微信等第三方工具中转"发出去再收回来",繁琐、打断工作流。

**目标**:打造一个局域网内共享的"便签/剪贴板"网页——任何设备把文字或图片贴上去,其他设备打开同一网址即可复制使用。

## 2. 已评估过的方案与结论

| 方案 | 结论 |
|---|---|
| PairDrop(WebRTC 浏览器 P2P) | **已试部署但不可用**。其设备卡片仅在 WebRTC 点对点连接成功后渲染;本网络环境跨设备 UDP 直连被阻断(同设备页面可连、跨设备 Windows↔Mac 失败),故设备不显示。属环境与 WebRTC 机制冲突,非部署问题。 |
| 微信等外部中转 | 现状,不满足。 |
| **本方案:局域网共享剪贴板网页** | 采用。中心服务器直连读写,不依赖 WebRTC,利用已验证畅通的 TCP 通路,可靠性高。 |

> 注:服务器上已有的 PairDrop 服务(占用 3001 端口)后续是否保留,另行决定,不阻塞本方案。

## 3. 角色与场景

- 角色:局域网内的所有设备使用者(单人/家庭使用,无多用户权限体系)。
- 典型场景:
  1. 在 Windows 上复制一段文字 → 贴到共享板 → 到 Mac 上打开页面复制使用。
  2. 在 Windows 截图 → Ctrl+V 粘贴到共享板 → 到 Mac 上查看/复制/下载该图片。
  3. 手机上打开同一网址,查看/复制共享板上的内容。

## 4. 功能需求

### 4.1 文字共享
- 页面上提供文本输入区,支持输入或粘贴文字(`Ctrl+V`),保存后发布到共享板。
- 发布后,其他设备打开页面即可看到该条文字,并可**一键复制**整条文字。
- 保留文字历史,按发布时间倒序排列(最新在上)。

### 4.2 图片共享
- 支持三种图片提交方式:
  - 从剪贴板粘贴图片(`Ctrl+V`);
  - 拖拽图片到页面;
  - 点击文件选择器上传。
- 图片保存后在页面上以缩略图列表展示(按时间倒序)。
- 点击缩略图可查看大图,并支持**复制图片到剪贴板**与**下载**。

### 4.3 当前剪贴板区 + 历史列表
- 页面顶部设"当前剪贴板"区:展示最近一次发布的文字(可一键复制)与最近一张图片。
- 其下为完整历史列表(所有文字 + 所有图片,按时间倒序),供回溯取用。

### 4.4 多设备一致性
- 同一时刻多台设备打开页面,内容一致。
- 提供"刷新"操作;可考虑轻量自动刷新/定时轮询(设计阶段决定,不强制实时推送)。

### 4.5 手机友好
- 页面为响应式布局,手机浏览器可正常打开、浏览、复制文字、保存图片。

## 5. 非功能需求

- **部署位置**:家中常开的 Linux 服务器。
- **端口**:避开服务器上已占用的端口(3000/3001/8000 等),选用独立端口(待设计确认,倾向 3002)。
- **访问方式**:局域网内浏览器直接访问 `http://<服务器IP>:<port>`,无需安装客户端。
- **访问控制**:无需密码(家庭局域网,已与用户确认)。
- **数据持久化**:文字与图片记录需持久化保存,服务重启后不丢失。
- **运行常驻**:部署为常驻服务,随系统开机自启(倾向 systemd 服务)。
- **性能**:单用户/家庭级负载,局域网内页面响应流畅即可。
- **技术约束**:服务器已有 Node.js v22,可零/低第三方依赖实现;也可用轻量方案(设计阶段定)。

## 6. 范围之外(明确不做)

- 不做多账号/登录/权限体系。
- 不做设备间 P2P 直传(数据统一经服务器存储)。
- 不做端到端加密(局域网自用,信任边界内)。
- 不做消息推送/实时通信(刷新或轮询即可)。
- 不做内容过期/清理策略(暂保留全部历史;如需可后续加)。

## 7. 待确认/待设计点

1. 数据存储形态:纯文件(JSON 索引 + 图片目录)或轻量数据库。
2. 文字是否限制长度/条数(防页面无限增长)。
3. 是否需要删除某条记录的功能。
4. 自动刷新机制(定时轮询间隔)。
5. 端口号最终选定。

## 8. 验收标准

- [ ] 在 Windows 浏览器粘贴一段文字并发布,Mac 浏览器打开页面能看到并一键复制成功。
- [ ] 在 Windows 截图后 `Ctrl+V` 粘贴到页面,Mac 端能看到缩略图、可放大、可下载/复制。
- [ ] 多台设备同时打开页面,内容一致。
- [ ] 重启服务后历史记录仍在。
- [ ] 手机浏览器打开页面可正常查看、复制文字、保存图片。
- [ ] 服务开机自启,常驻运行。
