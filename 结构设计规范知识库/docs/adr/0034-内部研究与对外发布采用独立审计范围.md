# ADR 0034：内部研究与对外发布采用独立审计范围

## 背景

当前扫描规范来源按 B 级登记，只允许内部研究和封闭验证，不允许对外检索或知识资产分发。原审计只有对外发布范围，无法准确表达“内部可用、外部不可发布”的状态。

## 决策

发布审计支持两个显式 profile：

- `external`：默认值，要求所有来源具备对外资格、真实封闭试用和明确交付决策。
- `internal-research`：只要求质量证据、运行 manifest 和来源台账声明内部研究或封闭验证用途；真实用户试用和对外交付决策不作为该 profile 的通过条件。

profile 必须由命令行显式选择，不能根据来源状态自动放宽默认对外门禁。内部 profile 的 `ready=true` 只表示受控内部研究可用，并额外返回 `external_release_ready=false`。

## 后果

- 本地研究和工程回归有了与版权边界相符的可验证状态，不再需要把内部可用误报为对外发布资格。
- 默认发布命令的阻断行为不变，任何对外服务或分发仍须完成来源权利、试用和交付决策。
- 未来新增来源时，必须明确其内部用途；禁止通过 profile 名称绕过权限字段或活动 manifest 范围校验。
