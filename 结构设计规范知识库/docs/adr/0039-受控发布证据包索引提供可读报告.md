## 背景

发布证据包索引用于人工补证，但只输出 JSON 会把责任人、来源字段和待办缺口埋在结构化数据中，增加校对和复审成本。

## 决策

校验器增加 `--markdown-output`，从同一个脱敏结果对象生成 Markdown。报告只展示状态、引用标识、哈希校验结果和缺口说明，不读取或复制授权原件、规范原文或密钥。

## 后果

- 发布负责人可以直接阅读缺口表格并安排补证。
- JSON 仍是自动化接口，Markdown 不会成为第二套事实来源。
- 可读性提升不改变 `--require-ready`、来源资格和发布审计的失败关闭语义。
