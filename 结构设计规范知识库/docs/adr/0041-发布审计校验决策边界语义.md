# ADR 0041：发布审计校验决策边界语义

> 状态：已接受

> 完整运行验证：外部 profile 仍 `ready=false`，内部研究 profile 在边界完整时 `ready=true`
> 验证证据：[发布审计决策边界语义校验验证记录](../releases/发布审计决策边界语义校验验证记录.md)、`tests/test_release_readiness.py`

## 背景

发布审计此前读取 D-001、D-002 仅用于输出上下文，内部研究 profile 不验证登记文档的安全边界。如果决策登记被误改为公共服务或对外分发，审计可能仍显示内部研究可用。

## 决策

发布审计必须读取 D-001、D-002，并在内部研究 profile 下校验既定边界语义：内容仅限内部研究和封闭验证、发布资格关闭；交付保留宿主机运行和知识包 CLI，不承诺安装器、桌面版或公共 Web 服务。缺失、空内容或边界语义被改写时，内部研究审计失败关闭。外部 profile 继续由 I-010、来源资格和其他外部证据共同决定，不因语义校验而放宽。

## 后果

- 决策登记成为内部研究审计的真实输入，而不只是展示信息。
- 审计可以在边界文档漂移时及时阻断，减少误用内部研究结果的风险。
- 语义标记不能替代真实授权、法律复核、用户试用或产品决策；这些事项仍需人工证据。
