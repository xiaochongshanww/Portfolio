# 架构决策记录（ADR）

> 状态：生效  
> 维护角色：工程负责人  
> 文档更新：2026-08-08  
> 流程核对：2026-08-08  
> 完整运行验证：不适用（当前为决策记录规则）  
> 验证证据：本目录的 ADR 列表与关联实现文档  
> 复核周期：发生关键决策时

ADR 用于记录会影响长期维护、成本、风险或兼容性的决定，例如模型供应商、知识内容等级、检索权威规则、结构化表发布机制、部署方案和鉴权方式。

命名：`NNNN-短标题.md`，例如 `0001-authority-ranking-for-specification-retrieval.md`。

已接受的 ADR 不可重写；决定变化时新增一份替代记录，并在旧记录中链接新记录。使用 [架构决策记录模板](../templates/架构决策记录模板.md)。
