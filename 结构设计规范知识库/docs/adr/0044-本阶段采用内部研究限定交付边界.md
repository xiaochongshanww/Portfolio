# ADR 0044：本阶段采用内部研究限定交付边界

> 状态：已接受
> 决策日期：2026-08-20
> 维护角色：产品与工程负责人
> 文档更新：2026-08-20
> 代码/流程核对：已核对产品边界、D-001/D-002、发布审计和路线图状态
> 完整运行验证：当前内部研究 profile 通过；外部发布仍受来源资格和真实试用门禁阻断
> 验证证据：[发布就绪审计验证记录](../releases/发布就绪审计验证记录.md)、[技术与产品待决策事项](../architecture/技术与产品待决策事项.md)、`scripts/audit_release_readiness.py`
> 关联评估/发布：I-010；[产品方向与边界](../product/产品方向与边界.md)
> 复核周期：开始外部试用、对外分发或交付方式变化时

## 背景

项目尚未完成来源权利复核、真实用户试用和市场验证。继续把安装器、公共 Web 服务、知识包分发或收费服务作为默认目标，会把尚未取得的权利和证据误写成产品承诺。

## 决策

当前阶段的交付边界确定为：仅在受控宿主机或项目成员范围内运行，用于内部研究、工程回归和封闭验证；运行知识包 CLI 可以作为内部技术入口。当前不承诺公共 Web 服务、安装器、桌面版、知识包对外分发、原始 PDF/截图/摘录传播或收费服务。

该决定关闭的是“当前阶段交付形态不明确”这一决策缺口，不授予任何内容传播权，也不代表产品市场验证完成。未来若扩大到项目成员之外，必须重新完成 D-001 内容权利复核、D-002 交付评估和 I-049 真实试用，并通过默认 `external` 发布审计。

## 后果

- I-010 可以标记为已完成，含义是当前阶段边界已明确，不是对外发布已获批准。
- I-048 来源权利和 I-049 真实试用仍保持未完成，外部发布门禁继续关闭。
- 工程可以继续围绕内部研究和受控验证优化，不应新增公共服务或安装器承诺。
