## 背景

来源台账负责记录来源范围和当前权限，受控证据包负责保存取得、权利复核、存储处置、试用和决策证据的引用。两者分开校验是必要的，但只阅读来源报告时看不到证据包中每个来源的收口状态，人工交接容易漏项。

## 决策

允许来源资格阅读报告通过 `--evidence-manifest` 读取并先校验受控证据包，然后在同一份 Markdown 中展示证据包总体状态、逐来源三类证据状态和缺口。台账 JSON、证据包 JSON 及各自校验器仍是机器事实来源；合并报告不复制授权原件、不包含规范原文或密钥，也不改变任何发布资格结论。

证据包校验失败、来源集合不一致、路径越界或哈希不匹配时，报告命令失败关闭且不写出结果文件。

## 后果

- 来源治理负责人可以在一份阅读报告中完成逐来源补证交接。
- 证据包仍可独立接入发布审计，不会因为生成 Markdown 而被误认为已收口。
- 当前真实权利和试用事实仍需人工提供，工程联动不能替代这些外部证据。
