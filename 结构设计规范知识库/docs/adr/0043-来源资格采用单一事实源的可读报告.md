# ADR 0043：来源资格采用单一事实源的可读报告

> 状态：已接受
> 决策日期：2026-08-20
> 维护角色：内容治理负责人
> 文档更新：2026-08-20
> 代码/流程核对：已核对 `render_source_register_report.py`、`validate_source_register.py` 和来源台账测试
> 完整运行验证：当前台账可生成报告；报告不会改变来源资格或发布审计结论
> 验证证据：[来源资格可读报告验证记录](../releases/来源资格可读报告验证记录.md)、`tests/test_source_register.py`
> 关联评估/发布：I-061；[来源登记台账](../governance/来源登记台账.md)
> 复核周期：来源台账 schema、发布审计或人工补证流程变化时

## 背景

来源资格涉及取得凭证、权利等级、使用范围、复核状态和仓库存储处置。直接阅读 JSON 不利于人工逐来源补证，也容易因为人工复制产生第二套状态来源。

## 决策

以来源登记台账 JSON 作为唯一事实来源。`render_source_register_report.py` 必须先调用来源台账校验器，再从同一份 JSON 生成 Markdown。报告只提供人工阅读和整改交接视图，不包含原文或授权原件，不授予任何使用权，也不改变 `--require-release-eligible` 和发布审计的失败关闭语义。

## 后果

- 内容治理负责人可以按来源逐项阅读待补字段，不需要直接阅读原始 JSON。
- 人工报告不会与机器台账形成第二套资格状态。
- 当前来源权利缺口仍然必须通过受控证据、权利复核和仓库存储处置完成，报告本身不能替代这些证据。
