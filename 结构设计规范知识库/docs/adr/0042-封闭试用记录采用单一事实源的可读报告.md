# ADR 0042：封闭试用记录采用单一事实源的可读报告

> 状态：已接受
> 决策日期：2026-08-20
> 维护角色：试用与质量负责人
> 文档更新：2026-08-20
> 代码/流程核对：已核对 `render_trial_record.py`、`validate_trial_record.py` 和试用记录测试
> 完整运行验证：计划记录和完成记录均可渲染；渲染不改变试用状态或发布审计结论
> 验证证据：[封闭试用记录可读报告验证记录](../releases/封闭试用记录可读报告验证记录.md)、`tests/test_trial_record.py`
> 关联评估/发布：I-060；[封闭试用方案](../product/封闭试用方案.md)
> 复核周期：试用记录 schema、人工审阅流程或数据清理规则变化时

## 背景

封闭试用治理要求保留适合人工阅读的记录，但直接阅读 JSON 容易遗漏前置条件、任务依据和收口结论，也容易因为人工复制产生第二套事实来源。

## 决策

以机器可读 JSON 作为唯一事实来源。`render_trial_record.py` 必须先调用 `validate_trial_record.py`，再从通过校验的同一记录生成 Markdown。计划记录可以生成可读报告，但必须明确尚未形成真实试用证据；完成或暂停记录仍由参与者反馈、原始页面复核和数据清理证据决定。

## 后果

- 负责人可以用 Markdown 审阅试用记录，不需要直接阅读 JSON。
- JSON、校验器和 Markdown 不会形成两套状态事实。
- 渲染器不会自动完成试用、批准来源权限或改变发布审计结果。
