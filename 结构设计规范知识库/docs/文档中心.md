## 维护原则

1. 改变接口、配置、检索策略、内容来源或发布方式时，必须同时检查受影响文档。
2. 不在 Git 中保存密钥、未授权扫描件、用户个人信息或版权沟通原件；文档只保存索引、哈希和状态。
3. 文档无法被实际操作或自动化验证支持时，标记为“草案”或“已知限制”，不能写成已具备能力。
