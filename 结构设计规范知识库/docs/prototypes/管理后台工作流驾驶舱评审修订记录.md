## 文档状态

- 适用对象：`管理后台工作流驾驶舱原型.html`
- 说明：本记录只描述原型层面的信息架构和交互修订，不代表当前 Vue 页面已经完成重构，也不代表原型已接入真实 API。

## 已采纳并实施

| 评审意见 | 实施结果 |
| --- | --- |
| 收敛主操作，避免两个 Primary CTA | 保留顶部“进入复杂表队列”为唯一主操作；当前阶段面板只保留“查看输入与产物”辅助操作。 |
| 强化当前阶段作为页面核心 | 当前阶段面板增加视觉强调，主任务、阻塞原因、完成条件和产物集中在同一工作区。 |
| 降低流程时间线与版本关系的竞争 | 主网格调整为当前阶段优先的比例；时间线和版本关系取消额外阴影，版本子项改为轻量的状态块。 |
| 减弱指标卡的 KPI 感和重复感 | 指标卡压缩内边距和数值字号，将“当前检索状态”改为“构建产物状态”，将 `Ready` 改为“已就绪”。 |
| 消除含糊的状态文案 | “等待输入”改为“未开始”或“待前置完成”；侧栏服务状态改为中文。 |
| 修正导航的 Active、Hover、Focus 语义 | Active 使用蓝色背景，Hover 使用轻量背景，Focus 使用 `:focus-visible` 轮廓，并为当前页增加 `aria-current`。 |
| 提高辅助信息可读性 | 提高顶部说明、面板说明、时间线和版本信息的字号与行高，减少低权重小字密集感。 |
| 支持窄屏查看 | 在 900px 和 560px 断点下切换为单列布局，工作流节点使用独立横向滚动区，避免页面级横向溢出。 |

## 有条件采纳

### 阶段进度条

暂未加入固定的“已完成 N / M”进度条。只有后端能提供同一阶段稳定、可解释的分子和分母时，才允许在正式页面显示进度；原型中使用固定演示数字会掩盖真实状态问题。

### 当前阶段工作区

已强化为驾驶舱的核心信息区，但具体的 PDF 对照、复杂表结构化、内容校对仍应进入各自的专业工作区。驾驶舱负责说明任务和入口，不替代这些工作区。

### 字体调整

已针对辅助信息提高字号和行高，没有整体放大所有文字。后续以真实任务密度和可读性测试结果继续调整。

## 不作为实施目标

- “8.5/10”或“9/10”属于主观评价，不作为工程验收标准。
- 暂不继续增加系统运行状态、更多统计卡、日志摘要等模块。当前原型已有待办清单和质量门禁预览，后续优先验证现有信息是否足够。
