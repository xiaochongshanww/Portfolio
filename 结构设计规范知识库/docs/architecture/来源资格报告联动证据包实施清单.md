> 状态：已完成
> 维护角色：来源治理与发布负责人
> 文档更新：2026-08-20
> 代码/流程核对：2026-08-20，来源台账报告、受控证据包校验和失败关闭边界已核对
> 完整运行验证：来源专项测试通过；当前证据包仍为草稿，未改变外部发布资格
> 验证证据：[来源资格报告联动证据包验证记录](../releases/来源资格报告联动证据包验证记录.md)、[ADR 0045](../adr/0045-来源资格报告联动受控证据包.md)
> 复核周期：来源台账、证据包 schema 或发布补证流程变化时

## 目标

把来源登记台账和受控发布证据包合并为一份人工阅读视图，逐来源展示取得、权利复核和存储处置证据状态，减少人工在两份 JSON/Markdown 之间来回比对。合并视图仍然是派生报告，不替代任一机器校验器。

## 实施清单

- [x] 1. 为 `scripts/render_source_register_report.py` 增加可选 `--evidence-manifest` 入口。
- [x] 2. 先校验证据包，再展示索引总体状态、逐来源三类证据状态和缺口。
- [x] 3. 证据包结构无效、来源集合漂移或路径越界时失败关闭且不生成报告。
- [x] 4. 增加通过索引和无效索引测试，不输出授权原件、规范原文或密钥。
- [x] 5. 同步来源台账、发布检查单、路线图、文档中心和 ADR。

## 操作入口

```powershell
python scripts/create_release_evidence_manifest.py --output <受限目录>\release-evidence.json
python scripts/render_source_register_report.py `
  --evidence-manifest <受限目录>\release-evidence.json `
  --output <受限目录>\source-register.md
python scripts/validate_release_evidence_manifest.py `
  --manifest <受限目录>\release-evidence.json --require-ready
```

报告只用于人工补证交接；`validate_release_evidence_manifest.py --require-ready`、`validate_source_register.py --require-release-eligible` 和发布审计仍分别保留各自的失败关闭语义。
