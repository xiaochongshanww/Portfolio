## 目标

在保留机器可读 JSON 为唯一事实来源的前提下，提供适合人工审阅的 Markdown 试用记录，避免参与者和负责人直接阅读原始 JSON；渲染结果不扩大来源权限，也不把计划记录变成真实试用证据。

## 实施清单

- [x] 1. 新增 `scripts/render_trial_record.py`，先调用现有试用记录校验器，再从同一 JSON 生成 Markdown。
- [x] 2. 渲染基本信息、前置确认、固定任务、缺陷反馈和收口结论。
- [x] 3. 计划记录明确显示尚未收口，不输出任何密钥、令牌、原始规范摘录或整页截图。
- [x] 4. 增加函数和 CLI 测试，并复用现有试用记录 schema 与失败关闭语义。
- [x] 5. 同步封闭试用方案、记录模板、路线图、文档中心和 ADR。

## 操作入口

```powershell
python scripts/validate_trial_record.py --record <受限目录>\trial.json
python scripts/render_trial_record.py --record <受限目录>\trial.json --output <受限目录>\trial.md
```

渲染前必须通过结构校验；完成或暂停记录仍需要负责人核对参与者反馈、原始页面和数据清理结果。
