## 实现

- [ ] 无人值守验证在 API 评估前执行 `/ready` 预检并输出具体未就绪原因。
- [ ] 常规与结构化评估在 `ok: false` 时令后台任务失败，同时保留报告路径和错误。
- [ ] 回答级盲测将请求失败汇总为顶层 `ok: false`，并保留已完成用例证据。
- [ ] `verify_quality.py --api-base` 直接驱动回答级盲测，确保问答与图片探测使用同一目标。
- [ ] 管理端回答盲测只使用受信任配置，不接受客户端任意 URL。
- [ ] 验证报告不再以“未知错误”代替评估器已有的错误信息。
