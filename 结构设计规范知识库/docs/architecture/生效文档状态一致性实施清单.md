## 背景

I-041 已由实现、验证记录和远程 CI 证明完成，但关联 ADR 0031 仍保留“代码/流程核对：实施中”和“完整运行验证：待回填”；文档中心的持续迭代摘要也停留在 I-040。现有文档门禁能检查链接、元数据字段存在和可达性，却不能识别字段内容已经过期。

## 目标

以持续迭代路线图中的状态列作为迭代完成状态源，建立最小、可解释的跨文档一致性检查。检查只约束明确关联已完成迭代的生效文档，不把真实质量待复验、产品待决策或模板中的未完成事项误判为工程漂移。

## 边界

- “工程完成但真实质量待复验”不是状态冲突；I-022、I-034 至 I-037 的外部证据缺口继续如实保留。
- 发布检查单、模板、治理草案和历史资料中的未勾选项不属于本门禁的迭代完成状态。
- 本轮不推断产品决策、内容授权或供应商成功能力，也不把文档一致性通过解释为发布质量通过。
