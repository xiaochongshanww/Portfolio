- [x] 为 `verify_quality.py` 增加显式 `--manage-api` 模式，并保持现有外部 API 模式兼容。
- [x] 托管模式只允许无凭据、无路径的 loopback HTTP 地址，端口已占用时失败关闭，不接管未知进程。
- [x] API 子进程继承受控环境，并把同一基址注入 `ANSWER_EVALUATION_API_BASE`；模型与 API Key 不进入命令行。
- [x] API 启动日志写入运行报告目录，所有错误摘要执行秘密脱敏。
- [x] API 启动、验证器子进程和回收形成单一所有权；成功、验证失败、启动失败和中断路径均不遗留进程。
