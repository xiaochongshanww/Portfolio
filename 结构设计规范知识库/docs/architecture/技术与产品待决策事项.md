## 本阶段已确定的边界

I-010 的当前阶段决策已记录于 [ADR 0044](../adr/0044-本阶段采用内部研究限定交付边界.md)：项目只面向受控内部研究、工程回归和封闭验证，不承诺公共 Web 服务、安装器、桌面版、知识包对外分发或收费服务。该决策不等于来源已获对外授权，也不等于真实用户试用已完成；未来扩大到项目成员之外时，仍须重新复核 D-001、D-002 和 I-049。

## 已确定边界

- 知识资产生产与轻量问答运行通过 [运行知识包 ADR](../adr/0001-运行知识包解耦构建与问答.md) 解耦。
- 技术校验通过不代表内容获得传播或商业使用授权。
- 未决事项不得通过临时代码开关悄然变成对外承诺。
- 知识包导出默认受质量门禁阻断，异常交付必须留下责任人和原因；详见 [ADR 0002](../adr/0002-知识包导出强制质量门禁.md)。该决定不替代 D-001 的内容分发授权判断。
