## 背景

当前生产来源按 B 级管理，台账允许其用于内部研究和封闭验证，但不允许截图、摘录、表格导出、对外检索或付费服务。原发布审计只有对外发布 profile，导致合法的内部研究路径也被显示为“发布资格阻断”。

## 实施清单

- [x] 1. 在来源台账校验结果中增加 `internal_research_eligible` 与对应阻断明细。
- [x] 2. 新增 `internal-research` 审计 profile，要求质量证据、运行 manifest 和来源内部用途均通过。

- [x] 4. C 级、`test_fixture` 和下架来源即使残留内部用途字段，也必须被内部资格校验阻断。
- [x] 5. 增加当前真实台账、profile 隔离、禁止来源和 CLI 行为测试。
- [x] 6. 更新路线图、文档中心、发布检查单、ADR 和验证记录。

## 边界

- `internal-research` 只证明当前活动数据可在项目成员范围内用于内部研究或封闭验证。
- 它不授予原始 PDF、截图、摘录、表格、知识包、回答或 API 的对外传播权。
- 它不替代真实用户封闭试用，也不完成 I-010、I-048 或 I-049。
- 对外发布仍必须使用默认 `external` profile，并通过 `--require-release-eligible` 对来源逐项校验。
