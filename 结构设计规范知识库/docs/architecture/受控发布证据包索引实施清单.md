## 目标

为来源权利、封闭试用、D-001/D-002 决策和可选精排证据提供一个受限目录中的机器可读索引。索引只保存证据引用、责任人、日期和文件哈希，不保存授权原件、规范内容、截图、密钥或联系人隐私。

## 实施清单

- [x] 1. 根据当前 production 来源生成不包含 test_only 夹具的索引草稿。
- [x] 2. 校验来源集合、来源文件映射、来源登记版本、证据状态和复核日期。
- [x] 3. 校验受限目录相对路径、文件 SHA-256、试用记录状态和密钥安全边界。
- [x] 4. 提供 `--require-ready`，让未补齐证据时明确失败关闭。
- [x] 5. 将索引校验作为发布审计的可选检查，不改变默认审计和内部研究 profile 的既有语义。
- [x] 6. 同步操作手册、发布检查单、路线图、文档中心和 ADR。

## 使用边界

- 证据包应放在受限目录，不能提交到 Git，也不能放入运行镜像。
- `ready=true` 只表示索引中的引用和结构已经收口，不授予任何内容分发权。
- 来源发布资格仍由 `validate_source_register.py --require-release-eligible` 决定，试用结论仍由 `validate_trial_record.py` 和负责人复核决定。
