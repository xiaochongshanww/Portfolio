## 契约与实现

- [x] 提供仅依赖标准库的跨平台 Compose 镜像拉取入口（证据：`scripts/pull_compose_images.py`）。
- [x] 服务名、尝试次数、初始等待和最大等待均由显式参数控制并严格校验（证据：CLI 帮助与参数测试）。
- [x] 只对受控瞬时错误重试；永久错误和未知错误立即失败并保留原始退出码（证据：故障分类测试）。
- [x] 采用有上限指数退避，输出稳定尝试编号、错误分类和最终结果，不输出环境秘密（证据：退避与脱敏测试）。
- [x] 单次 Compose 调用具备可配置超时，超时后受控重试并在耗尽时返回 124（证据：超时回归测试与 CI 显式 600 秒参数）。
- [x] OpenWebUI CI 先显式拉取，再以 `--pull never` 启动 Compose（证据：workflow 与交付契约测试）。
