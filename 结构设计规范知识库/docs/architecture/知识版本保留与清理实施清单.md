## 目标

让 `data/db_versions` 的空间占用可观测、可预测、可回收，同时保证活动版本、运行中候选、人工固定版本和必要回滚版本不会被自动清理。

## 实施清单

- [x] 建立版本清单与状态分类，至少区分活动、运行中、门禁通过、门禁失败、不完整、人工固定和未知旧版本。
- [x] 配置保留数量、成功/失败版本期限、磁盘高低水位和最短保护时间，并在启动前校验配置。
- [x] 生成持久化清理计划；计划包含版本指纹、删除原因、预计释放空间、到期时间和策略快照。
- [x] 执行前重新核对活动指针、运行任务、人工固定状态和版本指纹；任何变化均阻止对应版本删除。
- [x] 删除路径必须是版本根目录的普通直接子目录，不跟随符号链接或 Windows 重解析点；采用先改名为隔离墓碑再递归删除的方式。
- [x] 清理执行写入结构化审计事件和结果报告；部分失败不能伪装为成功。
- [x] 提供管理 API 和独立的版本管理界面，默认只生成计划，执行需要二次确认。
- [x] 自动化测试覆盖活动版本、运行任务、固定版本、近期回滚版本、过期计划、指纹变化、路径隔离和部分失败。
- [x] 更新配置参考、运行手册、接口参考、系统详细设计和文档中心。
- [ ] 后端全量测试、前端构建、容器冒烟和远程 CI 全部通过后，将 I-012 标记为完成。

## 非目标

- 本轮不自动上传、归档或删除原始 PDF。
- 本轮不提供任意路径删除接口。
- 本轮不把“磁盘超过高水位”解释为可以删除受保护版本；保护约束始终高于空间目标。
