## 目标

将 external 就绪审计中的来源资格、真实试用和精排质量三个未收口项合并为一份人工交接视图，明确责任角色、整改动作和验证条件，减少在多个 JSON、Markdown 和实施文档之间来回查找。

## 实施清单

- [x] 1. 只接受 `profile=external` 的权威审计 JSON，不自行推断或改写审计结论。
- [x] 2. 校验 `closure.ready`、阻断计数、提醒计数和逐项责任/动作/验证字段。
- [x] 3. 生成不包含规范原文、授权原件、用户数据和密钥的 Markdown 交接报告。
- [x] 4. 对 malformed、profile 漂移、状态不一致和 `--require-ready` 场景失败关闭。
- [x] 5. 完成本轮全量测试、静态检查和文档一致性门禁，并回填验证记录。

## 操作入口

```powershell
python scripts/audit_release_readiness.py `
  --profile external `
  --json-output data/audit/reports/readiness_external_latest.json `
  --markdown-output data/audit/reports/readiness_external_latest.md

python scripts/render_readiness_gap_report.py `
  --audit-json data/audit/reports/readiness_external_latest.json `
  --output data/audit/reports/readiness_gap_latest.md
```

`--require-ready` 只用于需要把报告作为发布前置条件的自动化流程；当前 external 审计仍应失败关闭。报告是审计结果的派生视图，不能通过编辑报告、路线图或状态字段解除阻断。
