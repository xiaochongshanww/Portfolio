## 1. 系统目标

系统将结构设计规范 PDF 解析为可追溯知识资产，并通过检索、权威排序、结构化表查询和多模态回答提供问答服务。它不是工程设计计算或审图结论工具；回答必须保留规范、页码、条文或表格来源。

## 2. 组件

```text
浏览器控制台 (Vue 3 + Tailwind) ─┐
Open WebUI / OpenAI 兼容客户端 ───┼─> FastAPI 服务
                                  │     ├─ 常规检索：Chroma + BM25 + 条文/权威排序
                                  │     ├─ 结构化表检索：已发布表资产的独立匹配支路
                                  │     ├─ 合并常规与结构化证据、生成 RAG 上下文与来源图片
                                  │     └─ 生成：MiMo OpenAI-compatible API
                                  │
PDF -> MinerU 或显式选择 PyMuPDF -> 审计与人工修正 -> manifest / Chroma / 图片资产
                                             └-> 运行知识包 -> 轻量问答环境
运行数据：活动数据库、manifest、结构化表、图片、原始 PDF、审计与任务日志
```

## 3. 运行时边界

- API 入口：`src.app.main:app`，由 FastAPI 创建路由和静态文件挂载。
- 控制台源码：`frontend/`；生产静态资产目录：`frontend/dist`。
- 问答模型：通过 `MIMO_BASE_URL`、`MIMO_MODEL` 和 `MIMO_API_KEY` 配置。
- 常规检索：使用智谱 Embedding 配置；向量结果由 BM25、条文匹配、权威性及表格意图规则重排。
- 结构化表检索不是常规结果的重排步骤：它从已发布的表资产独立匹配行数据，再与常规检索结果共同写入 RAG 上下文。
- 原始 PDF、解析产物、数据库、截图、审计和任务日志属于数据资产，不应混入代码发布包；运行环境通过受控目录或标准知识包安装所需资产。
- 轻量问答环境可以导入预构建运行知识包，不安装 MinerU，也不重复解析和向量化。必需资产是 manifest 与 Chroma 数据库；结构化表、解析图片和原始 PDF 按能力选择。
- Dockerfile 通过多阶段构建将 Vue 控制台打包进运行镜像；Compose 持久化完整 `data/`、数据库、日志和 Open WebUI 状态。容器实跑结论以 CI 和空环境验证记录为准。
- `/page-images/{doc}/{page}` 会按请求读取原始 PDF 并渲染页面。没有原始 PDF 时，问答服务不会再提供该动态 URL；若知识包含匹配的解析图片，则仍可通过 `/images/*` 提供静态证据，否则按纯文本证据回答。
- MinerU 不可用或解析失败时，当前构建会失败；PyMuPDF 是可人工显式选择的替代解析后端，不是自动降级链路。

## 4. 数据与质量流

1. PDF 以规范编号、名称、版本命名后进入受控数据源。
2. Pipeline 解析、生成元素和 chunk，并写入构建 manifest。
3. 规则审计和 AI 仅生成候选；文本、公式和表格修正必须经人工批准才可应用。
4. 复杂表先进入人工结构化队列，发布后执行结构化检索冒烟测试，失败则恢复上一版本或撤下首次版本。
5. 发布操作规程要求在对外发布前运行检索、结构化和回答级评估；详细门禁见 [质量运营流程](../operations/知识库维护与质量运营.md)。当前重建流程会先激活新数据库版本，质量门禁尚未接入为自动阻断条件；门禁失败时必须人工回退或暂停对外发布。

## 5. 关键架构决定

- 规范正文表格和正文条文优先于条文说明，避免“语义更像”压过“权威更高”。
- 结构化表不由 AI 自动发布，防止数值、单位、合并单元格和适用条件失真。
- 页面截图可通过 `/images/*` 和 `/page-images/{doc}/{page}` 提供；后者会按需从原始 PDF 渲染。当前实现未对这两类资源执行来源关联校验或 API Key 鉴权，不得将受限内容暴露到公网。
- 构建与问答通过版本化运行知识包解耦；原始 PDF 默认排除，导入前校验文件大小、SHA-256、路径安全和兼容性。详见 [ADR 0001](../adr/0001-运行知识包解耦构建与问答.md)。
- 模型供应商、检索策略和内容来源变化从本规则生效后必须记录 ADR 或发布记录，并执行相应评估；既有历史决定尚未补录为 ADR。
