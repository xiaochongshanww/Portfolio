## 目标

在保留机器可读来源台账为唯一事实来源的前提下，提供适合人工审阅的来源资格报告。报告只展示字段状态、整改缺口、允许用途和验证入口，不复制原始 PDF、授权原件、联系人信息或密钥，也不把报告本身当成授权证明。

## 实施清单

## 操作入口

```powershell
python scripts/validate_source_register.py
python scripts/render_source_register_report.py --output <受限目录>\source-register.md
python scripts/validate_source_register.py --require-release-eligible
```

报告适合人工准备取得凭证、权利复核和仓库存储处置；只有机器台账、受控证据和 `--require-release-eligible` 通过，才可以改变发布资格。
