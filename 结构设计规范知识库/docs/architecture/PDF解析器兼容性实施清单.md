## 问题定义

活动知识资产由 `magic-pdf 1.3.12` 生成，但当前代码默认查找 `mineru` 命令，完整构建依赖仍是无版本、无哈希的历史清单。外部 CLI 只要存在就能进入重建，无法证明实现、版本和输出结构与当前管道兼容。

## 目标行为

1. 重建在任何清理或解析写入前验证外部解析器实现与版本。
2. 默认只接受有真实资产证据的 `magic-pdf 1.3.12`，未验证版本默认失败关闭。
3. 受控迁移试验可以显式放行，但未验证状态必须贯穿 manifest 和产物审计。
4. 知识生产依赖使用独立、带哈希、可检查漂移的锁，不污染轻量运行环境。
5. 文档明确运行知识包用户不需要安装 MinerU，知识生产者使用哪套固定环境。

## 实施清单

### 兼容契约

- [ ] 定义解析器探测结果、支持矩阵和严格/试验策略。
- [ ] 默认外部 CLI 与已验证的 `magic-pdf 1.3.12` 一致。
- [ ] 版本探测覆盖命令缺失、超时、非零退出、乱码安全输出和无法识别版本。
- [ ] 未验证实现或版本在严格策略下给出可操作的阻断原因。

### 写入安全与审计

- [ ] 构建预检在清理候选产物之前执行并返回结构化兼容证据。
- [ ] 单文档解析在删除既有产物之前完成兼容检查。
- [ ] manifest 和单文档 `artifacts.json` 记录实现、版本、解析后路径、策略与兼容状态。
- [ ] 显式试验策略保留警告且不能伪装为已验证。

### 依赖与配置

- [ ] 新增知识生产环境直接依赖文件和带哈希锁文件。
- [ ] 依赖锁工具和 CI 漂移门禁覆盖知识生产锁。
- [ ] 移除无版本混合 `requirements.txt` 入口及其生效文档引用。
- [ ] `.env.example`、配置参考、README 和部署手册使用同一解析器契约。

### 自动化与证据

- [ ] 单元测试覆盖已验证版本通过及新主版本默认拒绝。
- [ ] 单元测试证明兼容预检失败不会清理已有产物。
- [ ] 单元测试覆盖显式试验策略和审计字段。
- [ ] 后端全量测试、依赖锁检查、文档门禁、前端门禁和容器门禁通过。
- [ ] 生成验证记录并在远程 CI 全部通过后关闭 I-017。

## 非目标

- 不在本轮宣布 MinerU 2.x/3.x 输出与当前管道兼容。
- 不在 CI 下载模型权重或执行真实扫描 PDF 全量 OCR。
- 不把重型解析器依赖加入 API 运行镜像或运行知识包。
- 不改变人工校对、候选激活和知识包质量门禁。
