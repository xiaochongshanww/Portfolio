## 背景

I-036 已建立不可变质量运行目录，但没有生命周期治理。I-037 在不削弱最新指针、脱敏历史和失败证据追溯的前提下，为封存与未封存运行提供只读清单和显式双阶段清理。

## 实施清单

- [x] 1. 固化质量运行保留决策
  - 接受 [ADR 0027](../adr/0027-质量运行证据采用保护集与双阶段清理.md)。
  - 明确保护集、默认期限、计划确认、执行前重检、路径隔离和审计边界。

- [x] 2. 建立安全清单与保护集
  - 区分封存、未封存和异常运行，计算大小、文件数、时间及内容指纹。
  - 保护最新指针、脱敏历史引用、最近封存运行和最小保护期内运行。
  - 指针、快照或目录异常时失败关闭，不生成删除候选。

- [x] 3. 实现持久化计划与受控执行
  - 计划记录策略、保护摘要、候选指纹和有效期。
  - 执行前重算保护集与指纹，任何漂移均拒绝执行。
  - 采用同根原子隔离、失败恢复、执行报告和 JSONL 审计事件。

- [x] 4. 提供跨平台运维入口
  - 提供 JSON 清单、生成计划和执行计划命令。
  - 支持显式报告目录、审计目录、快照目录和策略参数，不依赖 shell 专属语法。
  - 默认命令无删除副作用，执行必须提供计划标识和确认开关。

- [x] 5. 完成故障矩阵和真实目录验证
  - 覆盖最新/快照保护、期限与数量、计划过期、并发漂移、损坏指针、损坏快照、链接路径、隔离删除失败及恢复。
  - 在隔离副本验证当前两个封存运行和一个未封存残留的分类，不直接删除真实证据。
  - 通过 Ruff、专项、全量后端、前端、文档和远程 CI。

- [x] 6. 同步生效文档并关闭迭代
  - 更新架构、运维、参考、系统卡、文档中心和路线图。
  - 形成验证记录并取得远程十任务 CI 证据后，才把 I-037 标记为工程完成。

## 验收边界

- 工程验收证明生命周期工具不会误删受保护或变化中的运行，不证明内容质量通过。
- 清理不替代 `DATA_DIR` 备份；原始运行删除后，脱敏快照不能恢复详细报告。
- 本轮不提供后台定时删除，不改变验证器发布流程，也不解除任何内容授权限制。
