- [ ] 检索与回答评估管理请求仅接受内置标识并拒绝 `file`、`api_base` 和其他未知字段。
- [ ] 工作流从服务端映射解析评估文件，并在报告中写入 `evaluation_set_id`。
- [ ] 控制台和 `verify_quality.py` 不再向 API 发送文件系统路径。
- [ ] 验证器支持 `QUALITY_API_KEY`、`--api-key-file`、`QUALITY_API_KEY_FILE`、兼容文件和 `--no-api-key`。
- [ ] 验证器对 `/admin/status` 执行独立鉴权预检，关闭鉴权时允许空 Key，401/403 时给出可操作诊断。
