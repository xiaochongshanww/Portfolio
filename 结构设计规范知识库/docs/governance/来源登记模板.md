# 内容来源登记模板

> 状态：模板  
> 维护角色：内容治理负责人  
> 文档更新：2026-07-29  
> 流程核对：2026-07-29  
> 完整运行验证：不适用（模板尚未填入真实来源）  
> 验证证据：内容与来源治理政策中的字段要求  
> 复核周期：每季度或来源状态变化时  
> 访问级别：受限

每份原始内容对应一条登记。真实登记应存于受控系统，不提交 PDF、授权原件、联系人个人信息或付款凭证到 Git。

| 字段 | 示例或填写要求 |
| --- | --- |
| `source_id` | 稳定且不复用的来源标识 |
| 规范名称 / 编号 / 版本 | `GB 50009-2012` 等 |
| 原件 SHA-256 | 用于确认同一文件，不代替授权凭证 |
| 取得日期 | `YYYY-MM-DD` |
| 取得方式 | 官方下载、授权提供、采购或用户上传 |
| 凭证索引 | 受控证据库中的链接或编号 |
| 权利等级 | A、B 或 C，定义见内容与来源治理政策 |
| 允许用途 | 内部研究、封闭试用、公开检索、付费服务等 |
| 展示限制 | 原文摘录、整页截图、表格导出、下载是否允许 |
| 解析与数据版本 | parser、manifest、发布资产版本 |
| 复核日期 / 责任角色 | 权利状态的最近确认 |
| 下架状态 | active、suspended、removed 与原因索引 |

处理新来源前，先完成本登记；若无法判定权利等级，则按 B 级隔离处理。
