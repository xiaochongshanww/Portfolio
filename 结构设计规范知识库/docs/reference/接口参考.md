## 机器可读契约

服务启动后，使用以下地址获取当前接口契约：

```text
/openapi.json
/docs
```

任何客户端生成、请求/响应字段判断和错误处理，应以同版本运行服务导出的 OpenAPI 为准。Markdown 仅说明入口、兼容性和运营约束。

## 主要入口

| 路径 | 用途 |
| --- | --- |
| `POST /v1/chat/completions` | OpenAI-compatible 问答入口，支持流式响应 |
| `GET /v1/models` | 返回当前可用模型标识 |
| `GET /health` / `GET /ready` | 存活与依赖就绪检查 |
| `GET /metrics` | 服务指标快照 |
| `/admin/*` | 构建、审计、评估、校对和复杂表管理 |
| `/knowledge/*`、`/corrections/*` | 知识资产与修正相关接口 |

## 鉴权与兼容性

当 `API_AUTH_ENABLED=true` 时，当前实现只保护聊天、校对和管理接口，客户端可使用 `Authorization: Bearer <API_KEY>` 或 `X-API-Key: <API_KEY>`。模型列表、健康检查、指标、知识文档接口、图片、静态资源和 OpenAPI 文档均不在当前保护范围内。

**已知限制：** 当前路由保护规则未覆盖 `/images/*`、`/page-images/{doc}/{page}`、`/static/*`、`/knowledge/*`、`/docs` 和 `/openapi.json`。其中 `/page-images/{doc}/{page}` 会基于 `data/raw` 中的源 PDF 动态生成页面截图。在补齐受控资源访问前，禁止通过这些路径对公网提供受版权限制、用户上传或敏感页面截图。该限制必须在每次安全复核中确认。

## 变更策略

- 新增字段或端点：更新 OpenAPI，并在发布说明中描述。
- 删除字段、改变语义、提高鉴权要求：视为破坏性变更，至少在一个发布周期前通知调用方。
- 管理接口不是稳定的第三方公共 API；对外开放前需补齐角色权限、审计和版本策略。
