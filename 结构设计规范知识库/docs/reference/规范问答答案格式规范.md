# 规范问答答案格式规范

> 状态：生效  
> 维护角色：质量运营负责人  
> 文档更新：2026-08-08  
> 流程核对：2026-08-08  
> 完整运行验证：2026-07-05

> 复核周期：每次回答契约或提示词变化时

本文档定义结构设计规范知识库的回答输出要求，用于后续提示词、答案评估和人工验收。

## 通用原则

1. 结论先行：第一段直接回答用户问题。
2. 依据明确：必须给出规范名称、编号，以及条文号、表号或公式编号。
3. 正文优先：正文表格和正文条文优先于条文说明；条文说明只能作为解释或补充。
4. 单位完整：涉及数值时必须给出单位。
5. 条件完整：涉及取值时必须说明适用条件、限制条件和是否可提高。
6. 不确定不编造：材料中没有直接依据时，应说明未检索到直接依据，并列出已检索到的相邻依据。
7. 图片可追溯：引用截图时必须使用可渲染的 Markdown 图片链接，并标注页码。

## 表格取值类

适用于“取多少、标准值、系数、限值、查哪个表”等问题。

推荐格式：

```markdown
结论：办公楼楼面均布活荷载标准值取 2.0 kN/m²。

依据：《建筑结构荷载规范》GB 50009-2012 表5.1.1。

适用条件：该值适用于一般使用条件；当使用荷载较大、情况特殊或有专门要求时，应按实际情况采用。
```

要求：

- 必须给出表号。
- 必须区分“标准值、组合值系数、频遇值系数、准永久值系数”。
- 如果查询对象在表中没有直接行，应说明“可参照类别”，不能直接当作表内明示项。

## 条文原文类

适用于“第几条是什么、某条规定了什么”等问题。

推荐格式：

```markdown
结论：第8.2.1条规定的是……

依据：《建筑抗震设计规范》GB 50011-2010 第8.2.1条。

原文要点：
1. ...
2. ...
```

要求：

- 明确条文号。
- 如果召回 chunk 的元数据是章节号，但正文中包含精确条文号，应以正文精确条文号为准。
- 不应把条文说明当作条文正文回答。

## 公式类

适用于“公式是什么、如何计算、表达式是什么”等问题。

推荐格式：

```markdown
结论：雪荷载标准值可按 $s_k = \\mu_r s_0$ 计算。

依据：《建筑结构荷载规范》GB 50009-2012 相关雪荷载条文。

式中：
- $s_k$：雪荷载标准值，单位 kN/m²；
- $\\mu_r$：屋面积雪分布系数；
- $s_0$：基本雪压，单位 kN/m²。
```

要求：

- 保留 LaTeX 源码，便于前端渲染。
- 变量解释必须跟随公式。
- 若公式 OCR 明显异常，应提示需核对原 PDF 截图。

## 多规范对比类

适用于“两个规范有什么关系、区别是什么”等问题。

推荐格式：

```markdown
结论：两本规范关注层级不同：A 规定设计要求，B 规定分类原则。

依据：
- 《规范A》GB ...
- 《规范B》GB ...

对比：
| 维度 | 规范A | 规范B |
| --- | --- | --- |
| 作用 | ... | ... |
```

要求：

- 分别列出每本规范的依据。
- 不得把一个规范的条文推断为另一个规范的规定。

## 页面截图引用

推荐格式：

```markdown
![第30页](/page-images/GB%2050009-2012_.%E5%BB%BA%E7%AD%91%E7%BB%93%E6%9E%84%E8%8D%B7%E8%BD%BD%E8%A7%84%E8%8C%83.pdf/30)
```

要求：

- 使用绝对可访问的 API 路径或公网资源路径。
- 不输出无法渲染的裸文本图片路径。
- 多页依据按页码顺序排列。
