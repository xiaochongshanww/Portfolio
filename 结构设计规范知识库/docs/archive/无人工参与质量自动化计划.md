## 边界

本计划只处理能够通过确定性规则、测试或运行指标验收的事项。以下内容不得自动批准：

- 复杂表格中的数值、单位、条件、合并单元格和表注；
- 公式、强制性条文和结构安全参数的语义修正；
- AI 建议中包含 assumptions、缺失值或阻断质量提醒的内容；
- 规范正文与条文说明存在冲突时的权威解释。

## 实施清单

- [x] 2. 增加评估集契约校验
  - 检查重复 ID、空问题、无有效期望、未知类型和结构化用例缺失表号。
  - 常规评估集不得少于 100 项，结构化专项不得少于 12 项。
  - 契约不合法时评估命令必须失败。

- [x] 3. 增加统一自动质量门禁
  - 校验构建 manifest、必需产物、审计高风险项、两类评估结果和最低命中率。
  - 校验活动数据库指针、活动版本 manifest 与运行时集合数量一致。
  - 区分阻断项、警告项和仅供人工处理的信息项。
  - 输出机器可读 JSON 和适合运维阅读的 Markdown。

- [x] 4. 修正任务失败状态口径
  - 历史失败但同类型任务后来成功时，不再计为未解决失败。
  - 单独保留历史失败总数，避免丢失审计记录。
  - 检测长时间停留在 queued/running 的任务。

- [x] 5. 增加评估报告溯源与过期检测
  - 报告记录生成时间、评估集哈希和知识库数据版本。
  - 数据版本或评估集变化后，旧报告自动标记为过期。

- [x] 6. 增加一键无人值守验证入口
  - 自动执行后端测试、前端生产构建、常规评估、结构化评估和质量门禁。
  - 任一步失败时返回非零退出码并保留报告。

- [x] 7. 接入控制台质量运营视图
  - 展示门禁结论、未解决失败、报告是否过期和人工隔离项。
  - 人工待校对数量不作为自动门禁失败，但必须醒目标识。

- [x] 8. 完整回归并固化运维文档
  - 运行完整无人值守验证。
  - 更新标准命令、失败处理和自动化/人工边界。
