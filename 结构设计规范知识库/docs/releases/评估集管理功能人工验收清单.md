## 0. 隔离执行指引

推荐把验收分为“正式 API 只读检查”和“临时 API 变更检查”两部分：

- A-01～A-04、A-15 的只读页面检查可以使用当前知识库 API（默认 `http://127.0.0.1:8000`），禁止在该地址执行创建草稿、保存、发布、回退或删除。
- A-05～A-17 以及失败恢复检查必须使用临时数据根和临时端口。下面的 PowerShell 示例会把内置评估资产迁移到临时目录，页面变更不会触碰正式 `DATA_DIR`：

```powershell
$acceptanceRoot = Join-Path $env:TEMP ("kb-evaluation-acceptance-" + (Get-Date -Format "yyyyMMddHHmmss"))
$env:DATA_DIR = $acceptanceRoot
$env:DB_DIR = Join-Path $acceptanceRoot "db"
$env:IMG_DIR = Join-Path $acceptanceRoot "images"
$env:SOURCE_METADATA_PATH = Join-Path $acceptanceRoot "metadata/specs.json"
$env:PUBLIC_ASSET_BASE_URL = "http://127.0.0.1:8011"
$env:API_AUTH_ENABLED = "false"
$env:RATE_LIMIT_ENABLED = "false"
$env:ANSWER_EVALUATION_API_BASE = "http://127.0.0.1:8011"
.\.venv\Scripts\python.exe -m src.evaluation migrate --actor manual-acceptance
.\.venv\Scripts\python.exe -m uvicorn src.app.main:app --host 127.0.0.1 --port 8011 --log-level info
```

- 启动后访问 `http://127.0.0.1:8011/`，完成变更类验收；`Ctrl+C` 停止临时 API 后，确认 8011 端口已释放，并执行下面的清理命令，避免临时环境变量影响后续启动：

```powershell
Remove-Item Env:DATA_DIR, Env:DB_DIR, Env:IMG_DIR, Env:SOURCE_METADATA_PATH, Env:PUBLIC_ASSET_BASE_URL, Env:API_AUTH_ENABLED, Env:RATE_LIMIT_ENABLED, Env:ANSWER_EVALUATION_API_BASE -ErrorAction SilentlyContinue
```

验收记录只填写临时目录路径，不填写任何 API Key。
- 上述示例应在专用的新 PowerShell 窗口中执行，结束后关闭该窗口；不要在已经手工设置正式服务环境变量的终端中直接清理环境变量。显式覆盖数据库、图片和元数据路径，避免项目 `.env` 中的独立路径配置指向正式资产。
- 临时 API 若因没有正式知识库向量集合而使 `/ready` 返回 503，不影响评估集管理接口的草稿生命周期验收；此时应记录为环境提示，不得把它写成评估集功能通过或质量门禁通过。
- 验收结束后，如需清理临时目录，必须先确认路径解析结果位于 `$env:TEMP` 下，再删除该目录；不得使用通配符删除正式数据。
