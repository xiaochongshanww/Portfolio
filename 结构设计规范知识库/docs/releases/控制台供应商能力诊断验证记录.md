## 验证目标

证明操作者可以在控制台中显式诊断智谱 Embedding 与 MiMo 聊天能力，同时满足以下边界：页面加载和全局刷新不产生外部模型调用；检测结果不回显秘密、请求内容或模型输出；单次检测失败不被误写为持续健康或发布质量结论。

## 自动化证据

组件测试覆盖以下行为：

- 组件挂载和父级数据刷新（props 更新）时只显示“尚未检测”，不调用供应商端点；
- 人工点击后只调用一次生成客户端，并展示两项成功或稳定失败结果；
- 执行期间按钮禁用且重复点击不产生第二次请求；
- 401、429 与传输错误使用可读状态，不显示上游正文；
- 结果包含模型、延迟和可选 HTTP 状态。

使用独占 `127.0.0.1:8018` API、合成控制台凭据和合成失效供应商凭据进行验证，既有 `8000` 服务未被接管。验证结果：

| 场景 | 结果 |
| --- | --- |
| 首次鉴权后进入概览 | 面板显示“尚未检测”；服务访问日志没有供应商探测请求 |
| 人工点击检测 | 仅形成一个 `POST /admin/provider-probes` 请求；访问日志与结构化日志记录同一请求，接口返回 200 |
| 失效供应商凭据 | 智谱 Embedding 与 MiMo 聊天均显示“鉴权失败”、模型、延迟和 HTTP 401 |
| 桌面布局 | `1440×900` 下页面与面板均无横向溢出，面板宽度 420 px，内容完整 |
| 移动布局 | `390×844` 下页面与面板均无横向溢出，面板随可用宽度收缩至约 351 px |
| 浏览器运行状态 | 控制台 warning/error 为 0；临时视口已复位，验证标签页已关闭 |
| 进程隔离 | 8018 的父子进程身份与命令行核对后回收，端口确认关闭 |
