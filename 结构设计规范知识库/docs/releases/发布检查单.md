## 发布前

- [ ] 已说明功能、接口、配置、模型、检索或内容来源的变化。
- [ ] 已运行 `python scripts/validate_configuration_example.py` 和 `docker compose --env-file .env.example config --quiet`；若本次修改配置，已确认实际部署值通过 `python -m src.app.core.config`。
- [ ] 已运行 `python scripts/verify_quality.py --manage-api --api-base http://127.0.0.1:8017`（或显式连接已受控启动的目标 API），结果通过且报告未过期；使用的凭据来源和目标地址已记录但未泄露原值。
- [ ] 已运行 `python scripts/snapshot_quality_evidence.py --write` 和无 `--write` 的校验命令，审阅脱敏差异并确认 RAG 系统卡与最新质量报告状态一致；当前快照已进入不可变历史，确定性索引无漂移，且未提交 `data/audit/` 原始报告。
- [ ] 管理端重建的候选激活门禁已通过，报告数据版本与当前 `active_db.json` 一致；不得用它替代回答级完整发布门禁。
- [ ] 已构建 Vue 前端，并验证 `/static/index.html` 可访问。
- [ ] 已验证 `/health`、`/ready`、关键问答、图片资源和鉴权行为。
- [ ] 已在“版本管理”固定活动指针对应的回退版本；若使用运行知识包，当前包和上一版完整包均已保留并记录 `package_id`、数据版本与 SHA-256。
- [ ] 若交付运行知识包，已记录导出审计事件，并运行 `package-validate` 核对 `package_id`、数据版本、质量/豁免证据、能力声明和兼容警告。
- [ ] 已在目标环境运行 `package-probe`，确认 Chroma 可打开、集合数量一致且样本可读；矩阵外组合已附独立兼容记录。
- [ ] 已按 [ADR 0009](../adr/0009-运行知识恢复采用受控知识包重部署.md) 验证维护窗口、整包升级与整包回退步骤；不依赖手工修改活动指针。
- [ ] 已在 API 停止且无活动任务的维护窗口创建完整运行数据快照，在独立位置运行 `backup-validate`，并记录 `backup_id`、文件 SHA-256、受控存储位置和最近恢复演练。
- [ ] 已确认知识包是否包含原始 PDF；包内所有来源及派生产物均允许在目标范围分发和展示。
- [ ] 已确认 API Key、CORS、反向代理和日志脱敏符合目标环境要求。
- [ ] 使用 OpenWebUI 时，`openwebui-preflight` 已以退出码 0 完成，输出未泄露 Key，OpenWebUI `/health` 和 `/api/models` 已从客户端侧验证。
- [ ] OpenWebUI 连接采用环境托管模式；Key 轮换已按新旧并存、切换连接、移除旧 Key 的两阶段流程执行并留存非秘密证据。
- [ ] 已确认新增或变更内容的来源登记和展示权限。
- [ ] 已更新当前文档、OpenAPI/接口说明、系统卡和发布说明。

## 发布后

- [ ] 记录实际版本、时间、数据版本和质量报告链接。
- [ ] 执行生产冒烟测试并记录结果。
- [ ] 观察错误率、401/429、模型调用失败和图片访问失败。
- [ ] 出现回归时重新导入上一版完整知识包并执行同一组运行断言；同时创建事故记录。

## 发布阻断项

质量门禁失败、来源权利未确认、无法回退、关键接口未鉴权、控制台静态资源不可访问、回答引用错误或出现未解决高风险审计时，不得发布。
