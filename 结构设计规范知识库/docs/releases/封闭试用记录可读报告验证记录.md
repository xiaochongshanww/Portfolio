## 验证结果

| 场景 | 结果 |
| --- | --- |
| 完成记录渲染 | 输出基本信息、固定任务、依据引用、缺陷和收口结论 |
| 计划记录渲染 | 输出计划状态，并明确提示不构成真实试用完成证据 |
| 非法记录 | 先由现有校验器失败关闭，不生成 Markdown |
| 密钥安全 | 沿用试用记录校验器的密钥字段和值模式拒绝规则 |
| 单一事实源 | Markdown 由 JSON 生成，不允许人工编辑结果作为机器输入 |

## 操作方式

```powershell
python scripts/render_trial_record.py `
  --record <受限目录>\trial.json `
  --output <受限目录>\trial.md
```

Markdown 适合人工阅读，JSON 和 `validate_trial_record.py` 仍是审计与发布流程使用的机器事实来源。
