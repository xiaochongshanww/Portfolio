## 操作命令

```powershell
python scripts/create_release_evidence_manifest.py --output <受限目录>\release-evidence.json
python scripts/validate_release_evidence_manifest.py --manifest <受限目录>\release-evidence.json
python scripts/validate_release_evidence_manifest.py --manifest <受限目录>\release-evidence.json --require-ready
python scripts/audit_release_readiness.py --evidence-manifest <受限目录>\release-evidence.json
```

草稿校验通过不等于证据已完成；只有 `--require-ready` 通过，并且来源资格、运行 manifest、试用、交付决策和质量门禁分别通过，才可重新评估外部发布资格。
