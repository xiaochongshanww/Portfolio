## 结论

定稿原型已完成正式 Vue 前端重构。本次重构保留真实后端接口和既有业务能力，统一了管理后台外壳、生产流程导航、页面标题与主操作，并将六个定稿业务工作区映射到实际页面：规范来源目录、构建任务队列、内容校对工作台、复杂表结构化队列、质量验证中心和问答验证工作区；同时保留版本管理、工作流驾驶舱两个治理入口。

## 已实现范围

1. **统一工作流壳层**：深色侧边导航、当前工作区、流程分组、动态页面标题、后端状态和 API Key 鉴权入口。
2. **工作流驾驶舱**：展示当前阶段、下一步动作、阶段进度、流程时间线、版本关系、待办和质量门禁预览；没有质量评估记录时明确显示“待验证”。
3. **业务工作区接入**：来源上传与变更确认、任务提交与日志、版本操作、内容校对、复杂表处理、评估运行和问答验证均保留真实 API 调用。
4. **问答展示修复**：回答通过 `markdown-it` 渲染，Markdown 表格、公式文本、链接和引用截图不会再以原始 Markdown 路径直接显示；引用图片由浏览器渲染为图片元素。
5. **响应式布局**：校对、复杂表、评估、问答和构建任务页面在窄屏下纵向组织，在宽屏下按工作关系并排展示；构建任务日志在常见宽屏下与任务列表并排。
6. **统一状态语义**：区分后端不可用、等待鉴权、构建未完成、质量门禁待验证、质量阻断和可发布状态。

- 页面仍依赖后端 API、`/images` 资源路径和有效的 API Key；前端重构不替代后端服务和知识库数据。
- 定稿原型中的演示数据没有复制到生产页面；生产页面只显示 API 返回的状态、任务和资产。
- 本记录证明前端工程门禁通过，不等于 MinerU、真实供应商调用或来源权利审计重新通过；这些结论继续以各自验证记录为准。
