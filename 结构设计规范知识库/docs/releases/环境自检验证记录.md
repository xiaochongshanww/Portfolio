## 验证范围

I-029 将分散的解释器、依赖、配置、运行资产、凭据和 PDF 构建前置条件收敛为统一只读自检。验证目标包括：

1. `runtime` 与 `build` 配置只检查各自真实前置条件；
2. 默认文本可供人工排障，schema v1 JSON 和退出码可供自动化消费；
3. 缺失或损坏状态转换为稳定检查结果，不使诊断器自身崩溃；
4. 输出不含模型 Key 原值，运行不创建、修改或删除项目文件；
5. 自检结论不越权替代 `/ready`、知识包探针或发布质量门禁。

## 自动化证据

`tests/test_doctor.py` 覆盖以下矩阵：

- 完整轻量运行环境与完整 PDF 构建环境；
- AI 校对凭据缺失的非阻断警告；
- Python 主次版本不匹配、直接依赖缺失和精确锁版本漂移；
- 应用配置非法、模型凭据缺失、前端入口与活动 manifest 缺失；
- manifest 计数字段损坏、MinerU 不可用或不兼容；
- 稳定检查标识、汇总计数、文本说明、JSON 可解析性和 0/1 退出码；
- 敏感环境值替换及执行前后文件树内容、大小和修改时间不变。
