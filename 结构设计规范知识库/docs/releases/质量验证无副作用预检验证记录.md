## 验证范围

本记录验证完整质量执行前能否无副作用地确认 API 运行依赖与鉴权。它不执行任何模型请求，不产生新的检索或回答质量结论，也不更新脱敏质量证据历史。

## 专项测试

`python -m pytest tests/test_verify_quality.py -q` 结果为 33 passed。覆盖范围包括：

- 既有 API 的凭据、就绪与鉴权结果聚合；
- 未就绪时失败关闭并保留服务端原因；
- 托管 API 的启动、回收、启动失败和中断边界；
- 预检不覆盖既有 `verification_latest.json`；
- 输出不含 Key 且可由 ASCII 控制台解析。

## 当前环境真实预检

使用动态空闲 loopback 端口运行：

```powershell
python scripts/verify_quality.py --manage-api --preflight-only --api-base http://127.0.0.1:<动态端口> --no-api-key
```

| 检查 | 结果 |
| --- | --- |
| API 启动与回收 | 通过，未强制终止 |

| 集合与 manifest 计数 | 1635 / 1635，通过 |
| BM25、manifest、集合名 | 通过 |
| API 鉴权 | 当前关闭鉴权，显式无 Key 访问通过 |
| 模型凭据 | `ZHIPUAI_KEY_MISSING`、`MIMO_KEY_MISSING` |
