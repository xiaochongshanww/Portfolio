## 能力边界

- 本记录证明质量验证的目标地址、就绪预检、任务状态和错误传播契约，不证明当前模型回答质量有新的提升。
- 为避免把外部模型调用混入基础设施回归，本轮隔离进程测试没有执行 24 条真实回答盲测；发布时仍须在完整密钥和活动知识库环境运行 `python scripts/verify_quality.py`。
- 控制台发起回答盲测时，非默认端口或容器拓扑必须正确设置 `ANSWER_EVALUATION_API_BASE`。错误配置会快速失败，不会自动猜测其他服务地址。
- API 管理任务读取的评估文件路径仍属于服务端文件系统；本地验证器与远程 API 分离部署时，需要另行设计评估集上传或服务端资产标识，不应传入客户端任意路径或 URL。
