## 验证目标

证明知识包不只是能被 CLI 导入和直接打开 Chroma，而是可以在空运行数据根中完成以下真实链路：

1. 导入并激活知识包。
2. 使用同一 `DATA_DIR` 启动独立 FastAPI/Uvicorn 进程。
3. 由 API 加载活动指针、manifest、Chroma 和 BM25。
4. 通过 HTTP 核对就绪状态、文档数、chunk 数、数据版本和实际数据库路径。
5. 发生断言错误时停止子进程并清理隔离目录。

## 失败与修正记录

[CI #29](https://github.com/xiaochongshanww/Portfolio/actions/runs/31256563092) 的 Ubuntu 后端和前端任务通过，但 Windows 后端在新增的 CLI 初始化测试中失败。Runner 使用 `cp1252` 输出编码，`argparse` 写入中文帮助时触发 `UnicodeEncodeError`；失败发生在知识包 API 冷启动之前，依赖任务因此跳过。

修正后，管道 CLI 在启动时把 stdout/stderr 的不可编码字符策略设为 `backslashreplace`。测试显式使用 `PYTHONIOENCODING=cp1252`，验证帮助命令返回 0 且中文以 `\u` 转义安全输出；该处理不改变原本使用 ASCII JSON 的机器接口。修正提交和后续完整 CI 结果待补录。

## 已验证边界

- `DATA_DIR` 支持项目根相对路径和绝对路径；管道常量在进程启动时统一派生。
- `IMG_DIR` 与 `SOURCE_METADATA_PATH` 未设置时跟随数据根，显式覆盖优先。
- `DB_DIR` 保持无活动指针时的旧库回退，不参与已导入知识包的正常活动版本定位。
- 知识包导入和 API 冷启动不需要 MinerU，也不修改仓库真实 `data/`。

## 未证明事项

- 没有调用真实 Embedding 或回答模型，因此不证明供应商连通性和答案质量。
- 合成包不含原始 PDF，未验证动态页面截图；该能力受 D-005 和来源策略约束。
- 本轮不验证备份、回退、Open WebUI 鉴权、反向代理 TLS 或公网客户端。
- 通过技术矩阵不代表知识包内容获得外部分发授权。
