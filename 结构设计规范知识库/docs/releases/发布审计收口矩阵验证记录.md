| 检查项 | 结果 |
| --- | --- |
| `closure` JSON 汇总 | 包含就绪状态、开放项数量、阻断/提醒数量和检查编号 |
| 逐项收口条目 | 保留状态、阻断级别、责任角色、动作和验证条件 |
| 外部 profile | 原有来源、封闭试用、交付决策阻断保持不变；精排为非阻断提醒 |
| 内部研究 profile | `ready=true` 保持不变，未被收口矩阵改变为对外资格 |
| Markdown | 输出“收口矩阵”表格，并继续输出来源明细、整改行动和阻断原因 |
| 安全边界 | 不读取或输出凭据，不自动修改台账、试用记录、路线图或审计结论 |

python -m pytest -q tests/test_release_readiness.py
