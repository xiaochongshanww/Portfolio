## 验证范围

- 候选数据库、解析文本、图片、MinerU 与审计产物在版本目录隔离生成。
- 候选检索状态在不修改在线状态的前提下加载并运行常规、结构化评估。
- 门禁失败不修改活动指针或根 manifest。
- 指针写入后若内存状态替换失败，恢复旧活动指针和根 manifest。
- Chroma 候选加载失败保留原在线状态。
- API 与控制台区分预激活门禁和完整发布质量门禁。
