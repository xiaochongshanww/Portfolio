## 验证范围

本记录验证 `I-006` 受控图片资源访问，不证明来源内容获得公开传播授权。验证对象包括解析图片、原始 PDF 页面截图、RAG Markdown 引用和知识包迁移后的来源策略。

## 已验证行为

| 场景 | 预期与结果 |
| --- | --- |
| `public` 来源 | 无 API Key 可读取，通过 |
| `authenticated` 来源且鉴权开启 | API Key 或有效短期签名可读取，通过 |
| `authenticated` 来源且鉴权关闭 | 仅直接回环请求可读取，远程请求拒绝，通过 |
| `disabled` 来源 | 即使携带 API Key 也拒绝，通过 |
| 未登记来源 | 默认 `authenticated`，通过 |
| 无效或损坏策略 | 失败关闭为 `disabled`，通过 |
| 签名过期、换路径或超出最大有效期 | 拒绝，通过 |
| `/images/*` 目录穿越 | 目标路径限制在 `IMG_DIR`，越界返回 404，通过 |
| RAG 引用 | 受保护资源生成签名 URL，禁用资源不进入提示和引用，通过 |
| 知识包 v3 | 强制携带并校验完整 `runtime/metadata/specs.json`，导入后恢复到 `data/metadata/`，通过 |

真实活动 manifest 与来源策略核对结果为 5 份生产文档、5 条生产策略，缺失 0、字段不完整 0。轻量测试 PDF 仍保留在来源台账中用于自动化测试，但不进入当前生产运行 manifest；当前 5 份扫描规范的图片和页面策略均为 `authenticated`。

## 保留风险

1. 当前鉴权仍是单实例 API Key，不是用户、角色或租户 ACL。
2. 签名 URL 在有效期内可被持有者重放，生产环境必须使用 TLS 和合理短有效期。
3. `authenticated` 是技术访问范围，不代表 B 级扫描件可以公开服务或分发。
4. 已签发 URL 到期后，历史聊天需要重新生成引用才能再次显示受保护图片。
