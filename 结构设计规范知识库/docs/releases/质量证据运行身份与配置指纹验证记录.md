## 失败关闭验证

- 三类合成报告使用同一运行 ID、同一指纹时，完整门禁可以通过。
- 修改任一报告运行 ID 会触发 `evaluation_run_consistency`。
- 修改任一报告运行指纹或传入其他当前指纹会触发 `runtime_config_consistency`。
- 缺少 v1 字段的旧报告同时触发证据 schema、运行一致性和配置一致性阻断。
- 指纹测试确认检索配置或受控源码变化会改变哈希，模型/API Key、服务鉴权 Key 和资源签名 Key 不进入哈希输入。
- 管理状态接口测试确认只返回两个非敏感字段；非法、大小写不符或长度错误的运行 ID 在请求边界被拒绝。

## 可信边界

- 运行 ID 用于关联同一次受控验证中的报告，不是数字签名或远程证明。
- 当前安全模型信任管理 API、验证编排器和运行主机；本轮门禁解决误拼接、旧报告复用和配置漂移，不抵抗已取得主机或管理权限的恶意操作者。
- 若项目以后需要第三方可验证的发布证明，应增加签名清单、外部不可变日志或独立证明服务，不能仅复用本轮哈希字段。
