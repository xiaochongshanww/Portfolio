## 验证结果

| 场景 | 结果 |
| --- | --- |
| 当前台账渲染 | 输出总体资格、来源摘要、逐来源补证项和验证顺序 |
| 当前发布资格 | 正确显示当前对外资格被阻断，不伪造授权状态 |
| 内部研究资格 | 正确显示当前内部研究资格，不扩大为对外传播资格 |
| 来源缺口 | 保留取得凭证、权利复核和仓库存储处置等逐项阻断 |
| 原文与秘密保护 | 报告不读取或输出 PDF 内容、截图、授权原件、联系人信息和密钥 |
| 单一事实源 | Markdown 由通过校验的来源台账生成，不允许人工报告反向修改台账 |
| CLI 失败语义 | 台账结构不合法时不生成报告；`--require-release-eligible` 仍按原规则失败关闭 |

## 操作方式

```powershell
python scripts/render_source_register_report.py `
  --output <受限目录>\source-register.md
```

Markdown 供人工阅读和补证交接使用；来源台账 JSON、校验器和发布审计仍是机器判断的事实来源。
