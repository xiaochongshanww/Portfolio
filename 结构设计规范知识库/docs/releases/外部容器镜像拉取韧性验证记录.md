## 事故基线

提交 `3abfb58` 的 CI #75 首次运行中，OpenWebUI 任务在隐式拉取 `ghcr.io/open-webui/open-webui:v0.9.5` 时收到上游 `toomanyrequests`。不改代码重跑后十项任务全部通过，因此该样本被归类为外部仓库瞬时故障，而非应用回归。

## 已实现契约

1. `scripts/pull_compose_images.py` 只依赖 Python 标准库，由调用方显式给出 Compose 服务名。
2. 限流、网络/TLS 超时、连接中断、临时 DNS 和临时网关故障执行有限指数退避；永久与未知错误立即返回原退出码。
3. 单次 Compose 调用默认最多等待 600 秒，超时后受控重试，耗尽后返回 124；CI 另有 20 分钟总任务上限。
4. 参数在执行前校验，诊断输出包含尝试次数和错误分类，并脱敏敏感赋值、认证头和 URL 用户信息。
5. CI 与部署文档先执行显式拉取，再以 `--pull never` 启动，避免启动阶段再次隐式访问仓库。
