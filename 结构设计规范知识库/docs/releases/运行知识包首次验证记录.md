## 验证中发现并修复

- 根 manifest 与活动版本 manifest 曾分别报告 1636 和 1635；状态、管理、就绪和评估读取已统一以活动 manifest 为在线事实来源。
- `/ready` 新增 manifest chunk 数与 Chroma 实际计数一致性检查。
- 无原始 PDF 时不再向模型提供必然失效的 `/page-images/*` URL；保留可用解析图片或降级为纯文本证据。
- `package_id` 同时绑定数据版本和 payload，含 PDF 与不含 PDF 的包不再发生标识冲突。

## 未覆盖边界

- 本次只验证同一 Windows amd64、Chroma 1.5.9 环境的预构建索引迁移；跨操作系统、处理器架构和 Chroma 主版本仍需独立兼容矩阵。
- 当前知识包没有数字签名，哈希不能证明发布者身份。
- 本次验证不构成任何包内来源可对外分发的授权结论。
