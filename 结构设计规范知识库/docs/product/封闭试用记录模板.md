## 机器记录字段

如需执行自动校验，将本模板内容转换为 JSON 对象，顶层字段使用以下名称：

`schema_version`、`status`、`trial_id`、`participant_id`、`started_at`、`ended_at`、`delivery`、`environment_owner`、`source_register_version`、`data_cleanup_date`、`preflight`、`fixed_tasks`、`defects`、`conclusion`。

其中 `preflight` 记录五项前置确认；`fixed_tasks` 中每项至少记录任务编号、问题、是否找到依据、依据引用、是否需要人工复核和缺陷编号；`conclusion` 记录继续/调整/暂停、证据、未解决风险、数据清理、责任人和下一日期。不要在 JSON 或 Markdown 记录中保存 API Key、令牌、密码、原始规范摘录或整页截图。

填写后的 JSON 应先运行 `python scripts/validate_trial_record.py --record <trial-record.json>`，再运行 `python scripts/render_trial_record.py --record <trial-record.json> --output <trial-record.md>` 生成阅读版。阅读版是 JSON 的派生视图，不是第二份可编辑事实来源。
