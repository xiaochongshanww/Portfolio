# 商业化文档体系实施清单

## 目标

为结构设计规范知识库建立可长期维护的文档体系。它同时服务产品使用、工程交付、知识内容治理与 AI 风险治理；不以阶段性开发计划替代当前事实。

## 本轮范围

- [x] 建立 `docs/` 目录、唯一入口和文档生命周期规则。
- [x] 固化系统架构概览与事实来源层级。
- [x] 固化部署运行手册与当前已知交付边界。
- [x] 建立知识内容来源与版权治理政策。
- [x] 建立 RAG 系统卡和 AI 服务治理基线。
- [x] 建立发布检查单、ADR 与 Runbook 模板。
- [x] 在项目 README 接入新文档入口，并标明历史文档的定位。
- [x] 校验目录、链接和本轮清单状态。

## 验收标准

1. 新协作者可从 `docs/文档中心.md` 找到当前架构、部署、质量与治理入口。
2. 每份活文档均写明状态、负责人角色、复核周期与事实来源。
3. 内容来源、人工校对、AI 输出和发布门禁的责任边界可被独立审查。
4. 已完成的历史计划不会再被误读为当前架构或当前待办。
