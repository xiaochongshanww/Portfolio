# 规范知识排序实施计划

## 背景结论

当前 RAG 检索已经具备基础 hybrid search 能力：dense 语义召回、BM25 关键词召回、条文号精确召回。但结构规范问答需要进一步判断“谁最有资格回答问题”，尤其是取值类问题应优先使用规范正文表格，而不是关键词更密集的条文说明。

目标是把检索从“相似度排序”升级为“规范知识排序”。

## 目标

- 识别 chunk 的规范领域属性：正文、条文说明、附录、表格、图、公式。
- 识别表格 chunk 的表号和表名。
- 识别查询意图：取值类、条文类、定义类、构造要求类、公式类、一般类。
- 在检索候选上应用业务精排：取值类问题优先正文表格，条文说明降权。
- 保持现有 API 和 Open WebUI 使用方式不变。
