## 1. 目标

V2 重构解决了「结构迁移」：公开站 9 页、后台 17 页已进入各自的设计体系，渐变红线归零。本阶段解决剩下的两件事：

1. **覆盖缺口**：仍有 8 个页面从未进入 V2 体系（旧壳/旧视觉），约 8000+ 行；
2. **精细化**：已迁移页面在真实使用中暴露的层级、密度、一致性细节收尾。

完成标志：**全站任何路由（含旧书签）渲染后均符合对应设计体系，无旧渐变、无失效入口，文档与代码一致，用户验收通过。**

## 4. 每阶段通用门禁

- `npx vitest run` 全绿（新增页面必须带 spec）
- eslint 0 err / vue-tsc 0 err
- `npm run build` OK
- 浏览器实测（1920 + 390 两档抽查）
- 用户验收通过后提交推送

## 5. 风险与约束

1. **NewArticle 是最大风险项**——2800 行编辑器，交互复杂，只做视觉统一不做交互改动；若评审要求改交互，升级为独立项目；
2. 旧分类路由可能有外部书签——处置时必须保留 redirect；
3. Profile/AuthorProfile 涉及用户数据展示，字段增删需与后端确认；
4. 所有新页面禁止渐变/蓝紫/Hero Card（04 §3 红线持续有效）。

## 6. 执行节奏

每阶段 = 原型(如需) → 实施 → 门禁 → 浏览器验证 → 提交推送 → 用户验收。阶段间可暂停，完成状态以本文档标记为准。
