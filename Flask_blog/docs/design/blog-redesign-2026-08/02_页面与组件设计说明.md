# 02_页面与组件设计说明

> 目标：把已经确认的 HTML 原型转化为可实现、可验收的页面与组件规则。  
> 本文关注页面职责与组件结构，不重复定义基础颜色、字号等 Token。

---

## 1. 全局组件

建议公开站至少抽象：

```text
PublicHeader
PublicFooter
SearchTrigger
SearchOverlay
TagChip
MetaText
TechnicalVisual
ArticleFeedRow
TopicCard
ProjectCard
ReadingRail
ResponsiveTocDrawer
```

原则：

- 组件抽象以“视觉与行为稳定”为目标；
- 不为复用而过度抽象；
- 公开站避免直接暴露 Element Plus 默认视觉。

## 2. 首页

参考原型：

```text
xiaochongshan-2026-home-v2.html
```

### 2.1 页面职责

首页解决：

```text
最近写了什么？
正在做什么？
还有哪些文章？
长期关注哪些主题？
```

不承担：

- 完整个人介绍；
- 个人履历；
- 全部文章归档；
- 全部项目展示。

### 2.2 页面结构

```text
Header

Intro
├─ 最近在写，也在做。
├─ Python · AI · 软件工程 · 产品实践
└─ 持续更新中

最近更新
└─ Featured Article

正在进行
└─ Featured Project

最近文章
└─ Article Feed

长期专题
└─ Topic Grid

Footer
```

### 2.3 Intro

不是 Hero。

要求：

- 高度克制；
- 不使用大头像；
- 不使用两三行品牌口号；
- 不出现复杂按钮组；
- 只用于建立页面当前状态。

推荐文案：

```text
最近在写，也在做。
Python · AI · 软件工程 · 产品实践
```

### 2.4 最近更新

首页第一核心内容。

结构：

```text
Article Info | Technical Visual
```

左侧：

- 状态，例如“新文章”；
- 标题；
- 摘要；
- 专题；
- 日期；
- 阅读时间；
- 阅读入口。

右侧：

- 文章相关 Micro Visual。

要求：

- 整块可点击；
- 技术视觉必须有语义；
- 不使用无意义封面图；
- 不显示作者、点赞、收藏、评论。

### 2.5 正在进行

只展示当前最重要的一个项目。

结构：

```text
Dark Project Intro | Project Preview
```

项目 Intro：

- 状态；
- 项目名；
- 一段说明；
- 技术栈；
- 进入项目。

Preview：

- 项目真实截图；
- 或高度接近真实功能的模拟界面；
- 不使用普通插图。

### 2.6 最近文章

使用 Feed Row，不使用重复的大卡片。

每行：

```text
Date
Title + Summary
Micro Visual
Arrow
```

允许隐藏 Micro Visual 的场景：

- 移动端；
- 文章没有合适视觉表达；
- 页面信息密度过高。

禁止显示：

- 作者；
- 字数；
- 点赞；
- 收藏；
- 评论；
- 阅读量；
- 多个重复 Badge。

## 3. 专题页

参考：

```text
xiaochongshan-2026-topics-v1.html
```

专题不是 Category Tag 页面，而是长期维护的知识主题。

示例：

```text
AI 工程
软件设计
产品实践
Python
```

每张 Topic Card 包含：

- 名称；
- 简述；
- 文章数量；
- 当前是否持续更新；
- 最新文章。

Topic Card 可以使用 Soft Background，但不要使用高饱和色。

---

## 4. 专题详情页

参考：

```text
xiaochongshan-2026-topic-detail-v1.html
```

页面结构：

```text
Topic Identity
├─ 名称
├─ 描述
└─ 文章数量

推荐从这里开始
└─ Featured Article

全部文章
└─ Article Sequence
```

“推荐从这里开始”是核心组件。

专题不是单纯按时间排序，而应该给新读者一个明确入口。

## 5. 项目页

参考：

```text
xiaochongshan-2026-projects-v1.html
```

项目页不是传统 Portfolio。

核心表达：

> 我现在正在做什么，以及这些项目如何持续演进。

### 当前项目

只突出一个当前重点项目。

结构：

```text
Project Intro | Product Preview
```

当前项目权重大于历史项目。

### 其它项目

使用 2 列轻卡片。

展示：

- 项目名；
- 类型；
- 一句话说明；
- 技术栈；
- 状态。

避免：

- 每个项目巨大截图；
- 大量 GitHub Star / Commit 数据；
- 过度包装成“成功案例”。

---

## 6. 项目详情页

项目详情建议与 Article Detail 有明显联系，但不是文章页面。

推荐结构：

```text
Project Identity

Live Status
├─ 当前状态
├─ 最近更新
└─ Repo / Demo

Project Preview / Interactive Demo

为什么做

现在做到哪里

关键设计决策

相关技术文章

Changelog

Next
```

项目详情应该体现：

> 项目是持续进行的，而不是上线后冻结的作品页。

---

## 7. 归档页

参考：

```text
xiaochongshan-2026-archive-v1.html
```

归档只负责：

> 快速找到过去文章。

因此不使用卡片流。

结构：

```text
Year
└─ Date | Article Title | Topic
```

特点：

- 高密度；
- 低视觉噪声；
- 支持年份筛选；
- 未来可加关键字搜索。

归档页不重复摘要。

## 8. 搜索

参考：

```text
xiaochongshan-2026-search-v1.html
```

搜索范围：

```text
Article
Topic
Project
```

未来可加入：

```text
Page
Snippet
Documentation
```

### Search Overlay

Header 触发：

```text
⌘K / Ctrl+K
```

推荐桌面体验：

```text
Search Overlay
├─ Input
├─ Recent / Suggested
└─ Result List
```

支持：

- ESC 关闭；
- 上下方向键；
- Enter；
- 分类过滤。

### 搜索结果页

每个结果：

```text
Title
Matched Snippet
Type
Topic / Project
```

命中词允许使用 Signal Soft 高亮。

## 9. 关于页

参考：

```text
xiaochongshan-2026-about-v1.html
```

关于页不是个人简历。

不应写成：

```text
姓名
年龄
毕业学校
公司
技能百分比
```

而应该解释：

- 为什么有这个网站；
- 主要写什么；
- 最近在做什么；
- 技术兴趣如何演进。

推荐结构：

```text
About Narrative | Now

Timeline
```

Now 包含：

```text
正在写
正在做
主要技术
其它入口
```

## 10. Article Feed Row

这是公开站高频基础组件。

建议 Props：

```ts
interface ArticleFeedRow {
  title: string
  summary?: string
  publishedAt: string
  topic?: string
  href: string
  visual?: TechnicalVisual
}
```

桌面：

```text
Date | Title + Summary | Visual | →
```

移动端：

```text
Date
Title + Summary              →
```

---

## 11. Technical Visual

Technical Visual 不做统一图片模板。

建议定义类型：

```ts
type TechnicalVisual =
  | RagFlowVisual
  | GitGraphVisual
  | ArchitectureVisual
  | TokenVisual
  | MetricVisual
  | CustomVisual
```

它的任务是表达内容，不是装饰。

---

## 12. 页面状态

所有页面至少考虑：

```text
loading
empty
error
ready
```

例如：

专题无文章：

```text
这个专题还在整理中。
```

搜索无结果：

```text
没有找到与“xxx”相关的内容。
```

项目暂无 Demo：

```text
当前版本暂未开放在线体验。
```

不使用空白页面。

## 15. 页面验收

每个页面 Review 时至少检查：

- 页面职责是否清楚；
- 是否出现不必要个人信息；
- 是否出现旧版内容社区视觉；
- 是否为了“丰富”引入多余卡片；
- 是否保持中文优先；
- 是否与首页同一套视觉语言；
- 移动端是否合理退化；
- 每个数据字段是否真的有必要显示。
