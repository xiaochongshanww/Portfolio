# 04_管理后台设计规范_V2

> 状态：Design Baseline V2  
> 核心修订：Admin Shell 从“居中内容容器”升级为“Viewport-level Application Shell”。

## 1. Admin Shell 是应用壳，不是页面内容

后台根节点必须直接占满浏览器 viewport：

```text
Viewport
├─ Sidebar
└─ Admin Main
   ├─ Topbar
   └─ Workspace
```

禁止：

```text
Public Layout
└─ max-width Container
   └─ Admin Shell
```

这会让后台看起来像嵌入公开站中的小模块。

## 2. `/admin/*` 必须使用独立 Layout

进入后台后：

```text
/admin/*
→ AdminLayout
```

不得继续渲染：

```text
PublicHeader
PublicFooter
Public max-width Container
```

公开站与后台只通过：

```text
Topbar → 返回网站
```

连接。

## 3. Sidebar

Desktop：

```text
width: 220–232px
left: 0
top: 0
height: 100vh
```

Sidebar 属于 viewport-level shell，必须贴屏幕最左侧。

禁止将 Sidebar 放进：

```text
.center-container
```

## 4. Main

Main 占据 Sidebar 之外全部空间：

```css
.admin-layout {
  width: 100vw;
  min-height: 100vh;
  display: grid;
  grid-template-columns: 228px minmax(0, 1fr);
}
```

Main 不设置整体 `max-width`。

## 5. Workspace 与 Content

可以限制的是内部内容，而不是整个后台：

```text
Admin Main
└─ Workspace
   └─ Content max-width: 1280–1440px
```

推荐：

```css
.admin-workspace {
  padding: 32px;
}

.admin-content {
  width: min(100%, 1440px);
  margin: 0 auto;
}
```

## 6. Topbar

Topbar 只属于 Main 区域，不横跨 Sidebar。

```text
Sidebar Brand | Main Topbar
```

Topbar 高度约 58px。

## 7. 尺度修订

高信息密度不等于整体缩小。

V2 推荐：

```text
Page Title        26–28px
Description       13–14px
Sidebar Item      40px
Sidebar Text      13px
Metric Value      24–28px
Table Body        12–13px
Normal Button     34px
Primary Button    36px
```

密度应通过：

- 减少无效留白；
- 减少重复信息；
- 减少装饰容器；

而不是把所有元素缩到 80%。

## 8. Desktop 视觉比例

1920px 宽屏下目标：

```text
228px Sidebar
+
剩余 Main Workspace
```

内容区可以在 Main 内保持 1280–1440px 最大宽度。

## 9. 响应式

```text
>= 1050px
Sidebar 204–228px

720–1049px
Sidebar 缩窄 / 可折叠
Workspace padding 24px

< 720px
Sidebar Drawer
Main 100vw
Workspace padding 18px
```

## 10. P0 验收

- [ ] Sidebar 从 viewport x=0 开始
- [ ] `/admin` 不渲染 PublicHeader
- [ ] Admin Shell width = 100vw
- [ ] Sidebar height = 100vh
- [ ] Main 占据全部剩余宽度
- [ ] max-width 只作用于 Main 内部 Content
- [ ] Sidebar 显示/隐藏不改变 Public Layout，因为后台没有 Public Layout
- [ ] Page Title 视觉尺寸不低于约 26px
- [ ] Dashboard 在 1920px 屏幕上不再像缩小的嵌入式模块

## 11. 其它规范继续沿用

以下规则仍保持不变：

- 单一蓝色 Primary；
- 无蓝紫渐变；
- 无 Glow；
- 无页面 Hero Card；
- 普通 Card 弱阴影或无阴影；
- Page Header → Toolbar → Data View；
- Status 统一；
- 低频操作进入 `···`；
- Table Footer 统一分页。
